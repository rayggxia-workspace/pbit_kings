# 个人进度

每位成员在 `progress/<github-handle>/STATUS.md` 维护一份简短摘要，使用自己的 GitHub 用户名作为目录名。首次工作时创建，尚未开始的成员不需要空目录。这里对所有有仓库读取权限的人可见。

每次有实质进展、阻塞或交接时更新；任务讨论、负责人和任务状态仍以 Issue 为准，不在此复制完整任务列表。项目整体摘要由 `docs/STATUS.md` 维护。

复制下面的格式，替换占位文字：

```markdown
# <GitHub 用户名> 的进度

- 更新时间：YYYY-MM-DD HH:mm（注明时区）
- 当前任务：<本仓库 Issue 链接>
- 已完成：<简述本次实际完成内容，附 PR 或成果路径>
- 下一步：<下一项具体行动>
- 阻塞：<无，或需要谁提供什么>
- 验证：<实际检查及结果；未执行则说明原因>
- 交接：<需要时填写 docs/handoffs/ 中的文件链接>
```

同时处理多个 Issue 时各用一条短记录并附链接。不要提交账号口令、令牌或敏感个人资料。
